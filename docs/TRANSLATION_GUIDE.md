# Monster Roadtrip 번역 및 QA 기준

- 한글화 대상은 **3편 Monster Prom 3: Monster Roadtrip**, 1편/2편 자료는 조회 참고만 합니다.
- 원문 `work/source/`는 게임에서 읽기 전용으로 추출합니다. 원문 게임 파일을 바꾸지 않습니다.
- 원문 탭 구분 행의 **네 번째 필드(`index=3`) 텍스트만 번역**합니다.
  일반 `\t` 대사뿐 아니라 `>choice\t`, `>action\t`에서 네 번째 필드가
  사람이 읽는 선택지/행동 문구인 경우도 반드시 번역합니다. 그 외 이벤트
  헤더 `>>>`, 메타 지시문 `>event_type`, 화자·표정·배경·조건을 보존합니다.
- `%...%`, `[...]`, `<...>` 제어 토큰의 종류와 출현 횟수, 원문에 있는
  아라비아 숫자와 `+2`·`-1` 등 능력치 증감 표기를 정확히 유지합니다.
- 자연스럽고 문맥에 맞는 한국어로 욕설·성적/블랙코미디·메타 농담을 보존합니다.
  게임 코드나 구조 지시문을 일반 문장으로 착각해 번역하지 않습니다.
- 각각의 `translations/english_events_*.json`은 대응하는 원문 TextAsset의
  SHA256과 해당 텍스트 행 SHA256·물리 행 번호·이벤트 이름을 검증합니다.
- 번역을 완료하지 않은 대사는 일괄 자동 번역 또는 추정 문구를 넣지 않습니다.
- 원문 전체가 `...`처럼 말없는 반응인 경우에는 `……`를 허용합니다. 그 외
  일반 대사를 한글 없이 기호로만 대체하는 행위는 검증 단계에서 거부합니다.
- `build_ui_preview.py`가 만든 UI 메타텍스트는 아직 런타임에 로드되지 않습니다.

## 로드트립 자원·시스템 용어 (게임 내 문맥)

| 원문 시스템 용어 | 통일 한국어 | 비고 |
| --- | --- | --- |
| STAMINA | 체력 | 자동차 여행의 공유 자원 |
| HYPE | 흥 | 게임 시스템 자원, '열기'와 혼용 금지 |
| MAGIC | 마력 | *자원값*을 의미하는 경우. 일반 마법 행위는 '마법' 허용 |
| MIND | 정신 | 게임 시스템 자원 |
| SOUL | 영혼 | 게임 시스템 자원 |
| MONEY | 돈 | 게임 시스템 자원 |
| PRANK DOLLARZ | 장난 달러 | 기존 휴게소 번역 표현 |
| PRANK TOKENS | 장난 토큰 | 메타 상점/가챠 보상 |
| HITCHHIKER | 히치하이커 | 동승자를 가리키는 명칭 |
| REST STOP | 휴게소 | 여행 중 정차 장소 |
| DEEP CONVERSATION | 깊은 대화 | 게임 시스템의 심화 대화 |
| PASSIVE EFFECT | 지속 효과 | 히치하이커/캐릭터 고유 효과 |

우선 적용 대상은 **실제 게임 UI의 능력치/자원명**입니다. 같은 영단어라도
문장 내 일반 의미(예: 무대의 열기, 마법 주문)를 가리키면 고정 번역을
기계적으로 강요하지 않습니다. 메타텍스트 `STA_HYPE`·`STA_MAGIC`은
이번 추가 UI 번역에서 각각 `흥`·`마력`으로 일치시켰습니다.

본 가이드는 초기안이며 기존 한국어판의 용어집과 일관성을 재검증해야 합니다.
