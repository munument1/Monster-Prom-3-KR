### 최근 후속 배치 및 QA

- 본편 이벤트: **18,119/18,119개 전량 완료**. 100행씩 격리 초안을 작성하고 마지막

- 휴게소 이벤트: 5,768/5,768개 후보 완료. 엔딩 1,799/1,799, 버블 918/918,

  후보는 0개**입니다. 이는 미추출 게임 콘텐츠까지 자동으로 번역됐다는 뜻은 아닙니다.
- 주인공 변수 조사 감사에서 확인한 43개 오류를 전부 문맥 확인 후 교정했습니다:
  본편 40개 발생(39행), 휴게소 3개 발생(3행). `audit_protagonist_particles.py`는
  현재 후보 0건을 보고합니다. 일반 문장 종결 `잖아`는 일괄 변경하지 않았습니다.
- 델타 검증기는 기존 기준 행 중 조사 교정 40행을 정확한 suffix 변환만 허용하도록
  제한하며, 기존 승인 교정과 합쳐 총 56개 승인 교정만 허용합니다.
- `STA_HYPE`, `STA_MAGIC`, `STA_MIND`, `STA_MONEY`, `STA_SOUL`, `STA_STAMINA` 값은
  각각 `흥`, `마력`, `정신`, `돈`, `영혼`, `체력`으로 번역돼 있습니다. UI 미리보기는
  갱신했지만 마지막 BepInEx 로그(2026-10-24 22:22)는 이전 미리보기입니다. 기존 빌드의
  플레이 테스트는 수행됐으나, 최신 UI 미리보기를 새 게임 세션에서 다시 확인해야 합니다.
- 원문의 `100% OBJECTIFY`처럼 리터럴 퍼센트와 실제 변수가 인접할 때 발생하던
  플레이스홀더 오탐을 고쳤습니다. 검증기는 실제 변수 형식 `%[A-Za-z0-9_']+%`만
  변수로 인식하며, 회귀 테스트를 추가했습니다.

### 검증 방법 및 실게임 적용과의 차이

```powershell
python -X utf8 scripts\build_playtest.py
python -X utf8 scripts\verify_build_integrity.py
python -X utf8 scripts\verify_translation_delta.py
python -X utf8 scripts\show_translation_queue.py
python -X utf8 scripts\build_ui_preview.py
python -X utf8 scripts\audit_progress.py
python -X utf8 -m unittest discover -s tests -v
python -X utf8 scripts\prepare_camp_fonts.py --audit-only
```

- 번역 JSON은 **원본 TextAsset SHA-256**, 텍스트의 물리 line,
  이벤트명, 영어 텍스트 SHA-256을 보존하며, 원문에 없는 변수·태그·숫자·분기를
  새로 만들지 않습니다.
- 독립 `verify_build_integrity.py` 검사는 **번역한 행의 네 번째 필드 외에는
  11개 이벤트 TXT의 모든 행이 원본과 정확히 일치**해야 통과합니다.
- 3편의 기존 한국어 테스트 패치는 이전 시점의 이벤트 TXT를 사용합니다. 게임 플레이
  테스트는 수행됐지만, 최신 번역 배치와 2026-10-25에 갱신한 UI 미리보기를 게임에
  다시 적용해 확인하지는 않았습니다. 대사·선택지·저장/불러오기 회귀 검증을 이어갑니다.
- 2편의 Jua/감자꽃 글꼴은 현재 번역 한글 완성형 **1,468종 모두**를 포함하지만,
  모든 특수문자가 지원되는 것은 아닙니다. 신규 UI·대사 실게임 화면 검증 필요.
- `work/`, `build/` 아래 원본/폰트/게임 리소스는 Git에서 제외하며,
  **비공개 GitHub 저장소에도 이 바이너리들을 업로드하지 않습니다.**

현재 추출된 원문 기준 남은 번역 후보는 **0개**입니다. 다음 단계는 전역 용어·말투와
원문의 개발자 주석 연출, 실제 게임 화면에서의 폰트/줄바꿈·분기·저장·불러오기 회귀 검증입니다.

독립 표본 언어 검수에서 확인한 중간 수준 의미·용어 오류는 교정하고 전체 델타
검증을 다시 통과했습니다. **Joy / Zoe 모두 `조이`로 표기되는 동명이인 위험**이 확인돼
`TRANSLATION_GUIDE.md`에 별도 주의를 기록했습니다. 두 캐릭터의 고유명사를
임의로 일괄 변경하지 않고 시리즈 맥락을 확인하도록 관리합니다.
