## 이 ZIP의 용도

`scripts/package_source_preview.py`가 생성하는 ZIP은 **소스·한국어 번역 JSON·
플러그인 소스와 자체 빌드 DLL을 담은 로컬 테스트/재현용 키트**입니다.
게임 소유의 원문 TextAsset, 게임 실행 파일, Unity 번들, BepInEx 제3자 바이너리,
2편에서 추출한 글꼴은 포함하지 않습니다. **그대로 Steam 창작마당에 업로드할
수 있는 완성 모드/공식 릴리스 ZIP이라는 뜻이 아닙니다.**

## 본인 소유 게임에서 재생성

1. 설치된 Monster Prom 3: Monster Roadtrip의 `texts_assets_all.bundle`을 대상으로
   `scripts/extract_assets.py`를 실행합니다. 현재 스크립트의 기본 Steam 설치 경로가
   다르면 `GAME` 경로를 자신의 설치 경로에 맞게 수정합니다. Python 3의 `UnityPy`가
   필요하며, **원본 SHA가 일치하지 않는 게임 빌드에는 덮어쓰지 않습니다.**
2. `python -X utf8 scripts/build_playtest.py`와
   `python -X utf8 scripts/build_ui_preview.py`로 이벤트·UI 출력을 생성합니다.
   소스 추출 없이 ZIP 안의 번역 JSON만 게임에 직접 넣어서는 적용되지 않습니다.
3. 소유한 게임의 .NET Framework 4.7.2/x86 DLL 참조 및 BepInEx 5 Mono x86을
   사용해 플러그인을 구성합니다. 테스트 키트의 컴파일된 플러그인은 자체 작성 코드이며,
   BepInEx 코어 파일은 별도로 필요합니다. 선택형 Jua/감자꽃은 로컬 Monster Camp에서
   추출해야 합니다. 플러그인에는 맑은 고딕 대체 경로도 있지만 모든 환경에서의
   한글 출력은 확인 전입니다.
4. `scripts/install_local_playtest.ps1`은 기존 파일 충돌을 거부하고 추가 파일별
   SHA를 기록합니다. 이전 설치 기록이 남아 있다면 게임을 종료하고
   `scripts/uninstall_local_playtest.ps1`로 자기 파일만 안전하게 제거한 뒤 설치합니다.
   게임 원본 DLL, Unity 번들, 세이브 파일을 덮어쓰지 않습니다.

## 아직 확인해야 할 부분

- 이번 최신 30,255개 전체 번역 빌드를 게임에서 새로 실행해 메뉴·대사·분기·
  선택지·저장/불러오기·엔딩·폰트 줄바꿈을 확인해야 합니다. 과거 버전의 메인 메뉴
  한국어 출력과 Jua/감자꽃 로드는 이미 확인했지만 이번 갱신본의 실행 증거는 아닙니다.
- `TextMeshPro` 전용 일부 UI는 선택형 브리지의 적용 범위 밖일 수 있습니다.
- 원문의 대괄호형 개발자 주석처럼 **원문 보존이 필수인 태그** 일부는 한국어
  설명을 병기하는 방식입니다. 게임 화면에서 표기 방식을 추가로 검수해야 합니다.
- Steam 창작마당 로더는 확인된 원본 게임에서 지원 근거가 없으므로,
  창작마당 게시·다운로드만으로 설치된다고 안내하지 않습니다.

최신 로컬 빌드·테스트 기록은 `docs/INGAME_VALIDATION.md`와
`docs/TRANSLATION_PROGRESS.md`에서 관리합니다.
